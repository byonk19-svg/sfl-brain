# SFL Brain v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a locally runnable SFL Brain MVP whose web UI and five read-only MCP tools share one deterministic Supabase-backed recommendation model.

**Architecture:** Next.js App Router owns the server-rendered UI, server actions, and stateless MCP route. A focused Supabase repository layer produces domain records consumed by a pure recommendation engine, so UI and MCP rankings cannot drift.

**Tech Stack:** TypeScript, pnpm, Next.js App Router, React, Supabase/Postgres/Storage, `@supabase/supabase-js`, MCP TypeScript SDK v2, Zod v4, Vitest, Testing Library, Playwright smoke checks.
